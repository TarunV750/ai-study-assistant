# Phase 18: portfolio documentation and screenshots

Phase 18 turns the engineering repository into a reviewer-friendly case study.

- The root README now leads with the product outcome, deployed status, visual
  workspace, engineering highlights, architecture, local run path, and evidence.
- `docs/portfolio.md` explains the problem, solution, system design, key
  decisions, verification, debugging stories, and production evolution.
- `docs/architecture.md` now describes the implemented models, API boundary,
  differentiated retrieval policies, and citation enforcement rather than a
  future target.
- `docs/screenshots/course-lens-workspace.png` is a user-supplied application
  capture included without account identifiers, endpoints, or credentials.

The documentation avoids invented performance numbers, user claims, or fixed
AWS cost estimates. Every capability claim is backed by code, tests, or the
Phase 17 live verification record.
