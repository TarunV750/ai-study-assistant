# Incremental Delivery Roadmap

Each phase has its own implementation, verification, debugging, and Git commit.

1. **Repository and project structure** — establish boundaries and conventions.
2. **AWS resources and IAM** — choose IaC and define the security foundation.
3. **Private S3 storage and presigned uploads**.
4. **PDF extraction and document-processing Lambda**.
5. **Configurable overlapping text chunking**.
6. **Amazon Bedrock embeddings**.
7. **Amazon OpenSearch Serverless vector search**.
8. **Chunk and embedding indexing**.
9. **Semantic retrieval**.
10. **Grounded RAG question answering with Bedrock**.
11. **Amazon API Gateway REST endpoints**.
12. **React frontend**.
13. **Practice questions and summarization**.
14. **Citations and no-answer handling**.
15. **Security, validation, structured logging, and error handling**.
16. **Expanded automated tests**.
17. **AWS deployment and end-to-end testing**.
18. **Portfolio documentation and screenshots**.
19. **Complexity, security, cost, and bug review**.
20. **Interview-ready technical explanation**.
